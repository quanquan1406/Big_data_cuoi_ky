1. Tải và giải nén file zip hoặc từ github https://github.com/quanquan1406/Big_data_cuoi_ky
2. Điều hướng terminal đến thư mục 
3. Cài đặt môi trường python ảo: python -m venv venv
4. Kích hoạt môi trường ảo : venv\Scripts\activate
5. Cài đặt các thư viện cần thiết: pip install -r requirements.txt
6. Chạy chương trình streamlit: Streamlit run dashboard.py
